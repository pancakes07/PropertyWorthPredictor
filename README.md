# Property Worth Predictor

## Project Description
Property Worth Predictor is a Python package designed to estimate the value of residential properties and compare the estimated value with the seller's asking price.

It helps users identify whether a property appears overpriced, undervalued or fairly priced based on the provided details.

## Features
- Calculates basic property value.
- Adjusts estimated value according to property condition.
- Compares estimated value with the seller's asking price.
- Classifies properties into three categories:
  - OVERPRICED
  - UNDERVALUED
  - FAIRLY PRICED
- Generates a property valuation report.
- Handles invalid inputs.

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command:

py main.py

5. Enter the requested property details.

## Disclaimer
This project uses user-provided locality rates and predefined condition adjustments. It provides an academic estimation and should not be treated as a professional property valuation.
